# Echoes of Aetheria

Progetto per l'esame di Generative Artificial Intelligence: un gioco di carte originale sviluppato con supporto di strumenti generativi.

## Contenuto del progetto

- `docs/concept.md`: concept, lore, obiettivi di design e componenti.
- `docs/rulebook_it.md`: regolamento completo in italiano.
- `data/cards.csv`: database completo delle 45 carte.
- `docs/playtest_virtuale.md`: simulazione di playtest e note di bilanciamento.
- `docs/prompt_log.md`: registro dei prompt da includere in consegna.
- `docs/report_tecnico.md`: bozza del report tecnico richiesto dalle linee guida.
- `prototype/cards_print.html`: prototipo HTML stampabile delle carte, con layout 63x88 mm.
- `prototype/deck_full.html`: mazzo completo di 45 carte in HTML stampabile.
- `output/echoes_of_aetheria_deck_full.pdf`: esportazione PDF del mazzo completo.
- `web-game/index.html`: versione browser giocabile con 2-4 giocatori, umani o bot.
- `web-game/assets/cards/`: immagini delle carte divise per tipo, con template fallback.
- `web-game/src/rules/`: file JS separati per regole, scoring, Distorsioni e bot.

## Sintesi

In Echoes of Aetheria, 2-4 giocatori competono per stabilizzare antichi Nodi eterici usando Catalizzatori elementali e Distorsioni tattiche. La partita dura circa 15-20 minuti e premia pianificazione, lettura degli avversari e gestione delle risorse.

## Allineamento alle linee guida

Il progetto include:

- concept originale e non derivato;
- meccaniche e regole formali;
- tipologie di carte, attributi ed effetti;
- layout grafico prototipale;
- prompt usati per ideazione, testo, visual design e impaginazione;
- report tecnico sul workflow generativo.
