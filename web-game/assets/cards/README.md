# Card Artwork Folders

Use lowercase card IDs as filenames.

- Nodes: `nodes/n01.png`, `nodes/n02.png`, ...
- Fuoco Catalysts: `catalysts/fuoco/c01.png`, ...
- Acqua Catalysts: `catalysts/acqua/c08.png`, ...
- Vento Catalysts: `catalysts/vento/c15.png`, ...
- Terra Catalysts: `catalysts/terra/c22.png`, ...
- Distortions: `distortions/d01.png`, ...

The game tries the exact card image first. If that file is missing, it falls back to the matching template in `templates/`.
